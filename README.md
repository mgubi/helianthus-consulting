# helianthus-consulting

The website of Helianthus Consulting UK Ltd, served at
<https://helianthus-consulting.com>: a single static page in the house style
of the company's stationery (wordmark and sunflower mark, Jost and Source
Sans 3, sunflower amber).

- `index.html`, `style.css`: the page
- `assets/`: logos (SVG), favicons, fonts (with their SIL Open Font Licences)
- `CNAME`: the GitHub Pages custom domain
